# S15 - Sustentacion final

## 1. Introduccion

### 1.1 Proposito

Sustentar la solucion BI end-to-end con demo ejecutiva y defensa tecnica.

### 1.2 Resultado de aprendizaje

El estudiante presenta el valor de negocio, demuestra el pipeline, explica el modelo y defiende sus decisiones tecnicas y analiticas.

### 1.3 Producto de sesion

Demo final de la solucion BI y defensa tecnica del aporte individual.

## 2. Guion de sustentacion

Tiempo sugerido: 12 a 15 minutos por equipo.

1. Problema de negocio y usuario.
2. KPIs principales.
3. Arquitectura implementada.
4. Modelo dimensional.
5. Pipeline y validaciones.
6. Dashboard y hallazgos.
7. Decision recomendada.
8. Aportes individuales.

## 3. Evidencias minimas

| Evidencia | Obligatoria |
|---|---|
| Repositorio organizado | Si |
| DataMart construido | Si |
| Pipeline o evidencia de ingesta | Si |
| dbt o transformacion documentada | Si |
| Power BI funcional | Si |
| Validacion SQL vs BI | Si |
| Aporte individual | Si |

## 4. Defensa individual

Cada estudiante responde:

```text
Que construiste?
Que archivo o componente lo prueba?
Que problema resolviste?
Como validaste que funciona?
Que mejorarias?
```
