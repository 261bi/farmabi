# Unidad 2 - Sesión 7

## Sesión 12 - Evaluación final de solución BI

Este documento deja congelada la séptima sesión macro de la Unidad 2.

La sesión corresponde al bloque:

```text
Unidad 2 - Construcción del BI
Sesión 12 - Presentación y evaluación de proyectos BI
```

## Enfoque de la evaluación

La evaluación consiste en que cada alumno o equipo presente su propio caso de BI.

El caso puede ser distinto al caso farmacia, pero debe demostrar que el estudiante domina el flujo completo:

```text
problema de negocio -> datos -> modelo -> métricas -> visuales -> interpretación -> gobierno
```

No se evalúa solo si el reporte “se ve bien”. Se evalúa si la solución BI responde una pregunta real, usa datos consistentes, tiene métricas correctas, permite analizar y sostiene conclusiones de negocio.

## Alcance

- definición del problema de negocio
- descripción de fuentes de datos
- modelo de datos o modelo semántico
- medidas DAX principales
- tablero Power BI funcional
- filtros, segmentadores e interacción
- hallazgos de negocio
- validación de métricas
- gobierno del dato básico
- sustentación técnica y ejecutiva

## Producto evaluable

Cada alumno o equipo debe presentar una solución BI propia compuesta por:

- archivo `.pbix`
- fuente o muestra de datos utilizada
- explicación del problema de negocio
- modelo de datos o modelo semántico
- medidas principales
- dashboard con páginas analíticas
- hallazgos y recomendaciones
- evidencia de validación
- ficha breve de gobierno del dato

## Resultado esperado

Al finalizar la evaluación, el alumno debe ser capaz de explicar:

- qué problema resuelve su BI
- qué datos usa y de dónde vienen
- cuál es el grano principal de análisis
- qué métricas son críticas
- cómo se validaron los resultados
- qué hallazgos se obtuvieron
- qué decisiones podría tomar un usuario con el reporte
- qué limitaciones tiene la solución

## Cierre de unidad

La Unidad 2 se cierra cuando el alumno puede presentar una solución BI completa y defenderla con argumentos técnicos y de negocio.

```text
Un proyecto BI no se aprueba solo por tener visuales.
Se aprueba cuando convierte datos en decisiones confiables.
```
